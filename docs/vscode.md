# VSCode

## Key Bindings (Basic Editor)

The following key bindings are applying for both VS Code and Cursor. Those key bindings are additional to the default key bindings in VS Code and do not changes anything (except when it is specified).

| Action | Key Binding | Notes |
| ------ | ----------- | ------- |
| Go Back (Navigation) | Ctrl + [ | |
| Go Forward (Navigation) | Ctrl + ] | |
| Add Cursor Above | Ctrl + Option + ↑ | |
| Add Cursor Below | Ctrl + Option + ↓ | |
| Fold (Scope) | Ctrl + Cmd + [ | |
| Unfold (Scope) | Ctrl + Cmd + ] | |
| Fold (All) | Ctrl + Cmd + Shift + [ | |
| Unfold (All) | Ctrl + Cmd + Shift + ] | |
| Split Editor | Option + \ | This overrides the default Cmd+\ (because of 1Password). |
| Trigger Suggest | Ctrl + . | |
| Conditional Breakpoint | Ctrl + C, F9 | |
| Edit Conditional Breakpoint | Ctrl + E, F9 | |
